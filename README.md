# CK Capital — Control Room Redesign Concept

A responsive frontend concept built around three connected product surfaces:

- `index.html` — public Control Room / marketing experience
- `checkout.html` — account configuration + checkout flow
- `dashboard.html` — trader control room after login
- `styles.css` — shared visual system
- `app.js` — homepage interactions

## Flow
Homepage → Challenge Terminal → Checkout → Trader Dashboard

The checkout and dashboard are prototype UI surfaces. Connect their actions to CK Capital's real authentication, plan API, payment processor, and account data before production use.

Current public CK Capital values should be verified against the live site/backend before deployment because pricing and plan rules can change.
